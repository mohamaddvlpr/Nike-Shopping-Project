# NikeePro — Nike Online Store

A Nike-inspired e-commerce website built with HTML, CSS, JavaScript, PHP, and MySQL. This project provides a modern shopping experience with product browsing, user authentication, and database-driven functionality.

## Features

- Modern and responsive user interface
- Product listing and product details
- User registration and login
- PHP-based backend architecture
- MySQL database integration
- Product, category, and user management
- Organized MVC-style project structure

## Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layouts
- **JavaScript** — Client-side interactions
- **PHP** — Backend development
- **MySQL** — Database management
- **XAMPP** — Local development environment

## Installation

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository.
3. Place the project inside the XAMPP `htdocs` directory.
4. Start Apache and MySQL.
5. Create the project database in phpMyAdmin.
6. Import the database SQL file, if provided.
7. Configure the database connection settings.
8. Open the project in your browser using your local server URL.

## Database

The application is designed to work with a MySQL database and includes entities for:

- Users
- Categories
- Products
- Product Images

## Purpose

NikeePro is a web development project focused on building an e-commerce platform while practicing frontend development, backend architecture, database integration, and application organization.
